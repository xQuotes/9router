## 9Router: fixed upstream 400 code 11128 (channel verification)

- Upgraded 9router repo: `git merge --ff-only origin/master` → v0.5.91 → **v0.5.104** (`87a74e1b`). Backed up untracked `pnpm-lock.yaml` to /tmp before merge.
- Root cause of `API Error 400 [400] code:11128 "request illegal" / "channel verification failed, not an official client"`:
  the Tencent CodeBuddy/WorkBuddy backend (copilot.tencent.com, www.codebuddy.ai) requires the
  **X-Conversation-ID header family** on every chat request. 9Router's `codebuddy-cn`/`codebuddy-intl`
  providers sent none of them → upstream rejects with 11128 ("conversation id missing").
  Confirmed against `workbuddy2api-hub` `wb_identity.py` capture.
- Fix: added `open-sse/utils/codebuddyIdentity.js` (`codebuddyConversationHeaders()`) generating the
  X-Conversation-ID / -Request-ID / -Message-ID / -Root-Request-ID + trace (X-Trace-ID, traceparent, b3,
  X-B3-*) family, and overrode `buildHeaders` in `open-sse/executors/codebuddy-cn.js` and
  `open-sse/executors/codebuddy-intl.js` to inject it on every request.
- Validation: syntax-checked all 3 files (module mode); runtime-tested the helper → valid UUID headers.
  `node_modules` not reinstalled (fix needs no new deps); user must `npm install` + rebuild/restart for effect.
